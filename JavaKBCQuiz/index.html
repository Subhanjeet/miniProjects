Game Rules & Guide

Two Distinct Game Modes

  • Option 1 — Most Important Questions: 90 curated questions in randomized sequence. You start with 5 Lives (❤️❤️❤️❤️❤️). Each correct answer adds +1 point. Each wrong answer subtracts 1 point and costs 1 life. If you give 5 wrong answers (0 lives left), the game ends! You also have 5 classic KBC lifelines to help you.
  • Option 2 — Topic-Wise Challenge: 12 standalone modules with 10 questions each. No point deductions and no lifelines. If you select a wrong answer, the round ends immediately and explains the correct answer.

The Five Lifelines (Option 1 Only)

Each lifeline may be used only once per game:

  • 50:50: Removes two incorrect options from the current question, leaving the correct answer and one distractor.
  • Audience Poll: Displays a simulated percentage breakdown from a virtual audience.
  • Expert Advice: Provides a contextual hint based on the question topic without giving away the direct answer.
  • Skip Question: Bypasses the question without adding or subtracting any score.
  • Double Chance: Grants two attempts on the current question. If the first choice is wrong, you get a second chance without ending the game. A single question never awards more than +1 point.

Navigation & Review

  • Use the 🏠 Home button anytime to return to mode selection.
  • At the end of Option 1, use Review Answers to study all questions attempted along with complete explanations.
